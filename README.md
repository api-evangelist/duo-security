## APIs

### Duo Admin API

The Duo Admin API provides programmatic access to manage users, groups, phones, hardware tokens, WebAuthn credentials, bypass codes, and bulk operations across a Duo Security tenant. Requests are authenticated using HMAC-SHA1 signed HTTP Basic credentials derived from your integration key and secret key.
